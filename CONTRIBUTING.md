# Contributing to HackAtlas

Thanks for your interest in contributing. HackAtlas is open source, and contributions of all sizes are welcome.

## Getting started

1. Fork the repository.
2. Clone your fork.
3. Create a branch for your change.
4. Make and test your changes locally.
5. Commit your work with a clear message.
6. Push your branch and open a pull request.

## What you can contribute

- Bug fixes and accessibility improvements
- Responsive design and user experience improvements
- Verified open-source project listings
- Search, filtering, and discovery improvements
- Documentation and tests

## Project listing quality

If you suggest a project, provide its real repository URL and accurate information. Do not submit invented star counts, activity, issue labels, Hacktoberfest participation, or contribution availability. Clearly distinguish verified information from examples.

## Pull requests

- Keep changes focused and explain the problem they solve.
- Include screenshots for significant visual changes when practical.
- Test the interface on desktop and mobile sizes.
- Do not include secrets, access tokens, or private user data.

For larger changes, open an issue first so the approach can be discussed.

Thank you for helping make open source easier to discover.
